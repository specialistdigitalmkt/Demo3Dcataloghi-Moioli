PlaceholderValue — marks a technical value as not yet confirmed, instead of guessing a plausible number. A real brand content pattern (dedicated `--ph-*` tokens exist for it), not an invented component.

```jsx
Portata: <PlaceholderValue /> kN/m²
Rif. disegno: <PlaceholderValue>PM-2026-XXXX</PlaceholderValue>
```

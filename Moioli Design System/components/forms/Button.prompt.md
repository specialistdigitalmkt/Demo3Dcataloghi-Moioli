Button — the primary interactive action, used for form submits and key CTAs.

```jsx
<Button variant="accent">Richiedi preventivo</Button>
<Button variant="secondary" size="sm">Annulla</Button>
```

Variants: `primary` (navy — default site actions), `accent` (red — the interface accent, used sparingly), `secondary` (outlined), `ghost` (text-only). No documented press state in the brand kit; hover steps to the color's "Deep" tone.
